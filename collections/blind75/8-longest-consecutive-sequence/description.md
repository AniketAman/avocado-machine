# Longest Consecutive Sequence

**Topic:** Arrays & Hashing · **Difficulty:** Medium

Find the length of the longest run of consecutive integer values, ignoring their original order.

## TypeScript interface

`longestConsecutive(nums: number[]): number`

## Example

`nums = [2, 20, 4, 10, 3, 4, 5] → 4`

## Rules

Repeated values do not extend a run. Aim for linear time.

Source: [NeetCode problem](https://neetcode.io/problems/longest-consecutive-sequence/)
