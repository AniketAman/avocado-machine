# Top K Frequent Elements (Medium)

**Topic:** Arrays & Hashing · **Difficulty:** Medium

Return the k distinct integers that occur most often in nums.

## TypeScript interface

`topKFrequent(nums: number[], k: number): number[]`

## Example

`nums = [1, 2, 2, 3, 3, 3], k = 2 → [2, 3]`

## Rules

The set of top k elements is unique; output order is free.

Source: [NeetCode problem](https://neetcode.io/problems/top-k-elements-in-list/)
