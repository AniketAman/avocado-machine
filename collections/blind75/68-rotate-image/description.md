# Rotate Image

**Topic:** Math & Geometry · **Difficulty:** Medium

Rotate a square matrix 90 degrees clockwise.

## TypeScript interface

`rotate(matrix: number[][]): void`

## Example

`[[1, 2], [3, 4]] → [[3, 1], [4, 2]]`

## Rules

Mutate the supplied matrix in place.

Source: [NeetCode problem](https://neetcode.io/problems/rotate-matrix/)
