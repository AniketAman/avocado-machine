# Clone Graph (Medium)

**Topic:** Graphs · **Difficulty:** Medium

Create a deep copy of a connected undirected graph, beginning at the supplied node.

## TypeScript interface

`cloneGraph(node: GraphNode | null): GraphNode | null`

## Example

`1 ↔ 2 → a separate graph with the same adjacency`

## Rules

Copy every node and edge; no copied node may be the same object as an input node.

Source: [NeetCode problem](https://neetcode.io/problems/clone-graph/)
