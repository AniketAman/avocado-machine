# Search In Rotated Sorted Array

**Topic:** Binary Search · **Difficulty:** Medium

Find target in a rotated, strictly increasing array.

## TypeScript interface

`search(nums: number[], target: number): number`

## Example

`nums = [3, 4, 5, 6, 1, 2], target = 1 → 4`

## Rules

Return -1 when absent. Aim for logarithmic time.

Source: [NeetCode problem](https://neetcode.io/problems/find-target-in-rotated-sorted-array/)
