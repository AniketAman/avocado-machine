# Merge K Sorted Lists (Hard)

**Topic:** Linked List · **Difficulty:** Hard

Merge any number of ascending linked lists into one ascending linked list.

## TypeScript interface

`mergeKLists(lists: (ListNode | null)[]): ListNode | null`

## Example

`[[1, 2, 4], [1, 3, 5], [3, 6]] → [1, 1, 2, 3, 3, 4, 5, 6]`

## Rules

An empty array of lists produces an empty list.

Source: [NeetCode problem](https://neetcode.io/problems/merge-k-sorted-linked-lists/)
