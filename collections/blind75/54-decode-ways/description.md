# Decode Ways (Medium)

**Topic:** 1-D Dynamic Programming · **Difficulty:** Medium

Count ways to map a digit string into letters using 1→A through 26→Z.

## TypeScript interface

`numDecodings(s: string): number`

## Example

`s = "12" → 2`

## Rules

A token cannot begin with zero.

Source: [NeetCode problem](https://neetcode.io/problems/decode-ways/)
