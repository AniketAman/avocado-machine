# Graph Valid Tree (Medium)

**Topic:** Graphs · **Difficulty:** Medium

Check whether undirected edges connect all n nodes without a cycle.

## TypeScript interface

`validTree(n: number, edges: number[][]): boolean`

## Example

`n = 5, edges = [[0, 1], [0, 2], [0, 3], [1, 4]] → true`

## Rules

Nodes are numbered 0 through n-1; n is at least one.

Source: [NeetCode problem](https://neetcode.io/problems/valid-tree/)
