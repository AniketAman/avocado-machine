# Subtree of Another Tree

**Topic:** Trees · **Difficulty:** Easy

Determine whether some node of root begins a tree identical to subRoot.

## TypeScript interface

`isSubtree(root: TreeNode | null, subRoot: TreeNode | null): boolean`

## Example

`root = [1, 2, 3, 4, 5], subRoot = [2, 4, 5] → true`

## Rules

A matching node must include all descendants and their positions.

Source: [NeetCode problem](https://neetcode.io/problems/subtree-of-a-binary-tree/)
