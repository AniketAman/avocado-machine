# Find Minimum In Rotated Sorted Array

**Topic:** Binary Search · **Difficulty:** Medium

Find the minimum in a rotated, strictly increasing array.

## TypeScript interface

`findMin(nums: number[]): number`

## Example

`nums = [3, 4, 5, 6, 1, 2] → 1`

## Rules

All values are unique. Aim for logarithmic time.

Source: [NeetCode problem](https://neetcode.io/problems/find-minimum-in-rotated-sorted-array/)
