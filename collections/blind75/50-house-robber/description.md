# House Robber (Medium)

**Topic:** 1-D Dynamic Programming · **Difficulty:** Medium

Maximize money taken from a row of houses without taking adjacent houses.

## TypeScript interface

`rob(nums: number[]): number`

## Example

`nums = [1, 1, 3, 3] → 4`

## Rules

House values are nonnegative.

Source: [NeetCode problem](https://neetcode.io/problems/house-robber/)
