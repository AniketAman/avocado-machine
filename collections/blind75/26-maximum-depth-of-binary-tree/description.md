# Maximum Depth of Binary Tree (Easy)

**Topic:** Trees · **Difficulty:** Easy

Count the nodes on the longest path from the root down to a leaf.

## TypeScript interface

`maxDepth(root: TreeNode | null): number`

## Example

`[1, 2, 3, null, null, 4] → 3`

## Rules

An empty tree has depth zero.

Source: [NeetCode problem](https://neetcode.io/problems/depth-of-binary-tree/)
