# Best Time to Buy And Sell Stock

**Topic:** Sliding Window · **Difficulty:** Easy

Choose one day to buy and a later day to sell; maximize the profit.

## TypeScript interface

`maxProfit(prices: number[]): number`

## Example

`prices = [10, 1, 5, 6, 7, 1] → 6`

## Rules

Return zero if no profitable trade exists.

Source: [NeetCode problem](https://neetcode.io/problems/buy-and-sell-crypto/)
