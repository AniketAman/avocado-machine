# Word Search (Medium)

**Topic:** Backtracking · **Difficulty:** Medium

Check whether word can be traced through horizontally or vertically adjacent cells.

## TypeScript interface

`exist(board: string[][], word: string): boolean`

## Example

`board = [["A", "B"], ["C", "D"]], word = "ABD" → true`

## Rules

A cell may be used only once in one path.

Source: [NeetCode problem](https://neetcode.io/problems/search-for-word/)
