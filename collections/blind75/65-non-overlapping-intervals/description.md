# Non Overlapping Intervals (Medium)

**Topic:** Intervals · **Difficulty:** Medium

Find the fewest intervals to remove so the remainder have no positive-length overlap.

## TypeScript interface

`eraseOverlapIntervals(intervals: number[][]): number`

## Example

`intervals = [[1, 2], [2, 4], [1, 4]] → 1`

## Rules

Intervals that only touch at endpoints may both remain.

Source: [NeetCode problem](https://neetcode.io/problems/non-overlapping-intervals/)
