# Set Matrix Zeroes (Medium)

**Topic:** Math & Geometry · **Difficulty:** Medium

If any original cell is zero, zero its entire row and column.

## TypeScript interface

`setZeroes(matrix: number[][]): void`

## Example

`[[1, 2, 3], [4, 0, 5], [6, 7, 8]] → [[1, 0, 3], [0, 0, 0], [6, 0, 8]]`

## Rules

Mutate the supplied matrix in place. Decisions use the original zero positions.

Source: [NeetCode problem](https://neetcode.io/problems/set-zeroes-in-matrix/)
