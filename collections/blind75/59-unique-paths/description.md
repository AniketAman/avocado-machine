# Unique Paths (Medium)

**Topic:** 2-D Dynamic Programming · **Difficulty:** Medium

Count paths from the top-left to bottom-right cell of an m-by-n grid.

## TypeScript interface

`uniquePaths(m: number, n: number): number`

## Example

`m = 3, n = 3 → 6`

## Rules

At each step, move only right or down.

Source: [NeetCode problem](https://neetcode.io/problems/count-paths/)
