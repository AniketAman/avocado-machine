# Number of Connected Components In An Undirected Graph (Medium)

**Topic:** Graphs · **Difficulty:** Medium

Count the connected parts of an undirected graph, including isolated nodes.

## TypeScript interface

`countComponents(n: number, edges: number[][]): number`

## Example

`n = 5, edges = [[0, 1], [1, 2], [3, 4]] → 2`

## Rules

Nodes are numbered 0 through n-1.

Source: [NeetCode problem](https://neetcode.io/problems/count-connected-components/)
