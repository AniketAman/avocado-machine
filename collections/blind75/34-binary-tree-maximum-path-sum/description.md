# Binary Tree Maximum Path Sum

**Topic:** Trees · **Difficulty:** Hard

Find the largest sum along any non-empty simple path through a binary tree.

## TypeScript interface

`maxPathSum(root: TreeNode | null): number`

## Example

`[1, 2, 3] → 6`

## Rules

The path may start and end anywhere; it need not pass through the root.

Source: [NeetCode problem](https://neetcode.io/problems/binary-tree-maximum-path-sum/)
