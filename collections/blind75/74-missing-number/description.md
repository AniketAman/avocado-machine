# Missing Number (Easy)

**Topic:** Bit Manipulation · **Difficulty:** Easy

Find the one absent value from 0 through n, where nums contains n distinct values.

## TypeScript interface

`missingNumber(nums: number[]): number`

## Example

`nums = [0, 2] → 1`

## Rules

The missing value may be zero or n.

Source: [NeetCode problem](https://neetcode.io/problems/missing-number/)
