# Merge Two Sorted Lists (Easy)

**Topic:** Linked List · **Difficulty:** Easy

Merge two ascending linked lists into one ascending list.

## TypeScript interface

`mergeTwoLists(list1: ListNode | null, list2: ListNode | null): ListNode | null`

## Example

`[1, 2, 4] and [1, 3, 5] → [1, 1, 2, 3, 4, 5]`

## Rules

Use the existing nodes from both lists.

Source: [NeetCode problem](https://neetcode.io/problems/merge-two-sorted-linked-lists/)
