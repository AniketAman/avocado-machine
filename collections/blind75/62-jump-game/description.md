# Jump Game

**Topic:** Greedy · **Difficulty:** Medium

Determine whether jumps of up to nums[i] positions can reach the last index from index zero.

## TypeScript interface

`canJump(nums: number[]): boolean`

## Example

`nums = [1, 2, 0, 1, 0] → true`

## Rules

Jump lengths are nonnegative.

Source: [NeetCode problem](https://neetcode.io/problems/jump-game/)
