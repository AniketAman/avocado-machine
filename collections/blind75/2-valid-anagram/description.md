# Valid Anagram

**Topic:** Arrays & Hashing · **Difficulty:** Easy

Determine whether s and t contain exactly the same letters with the same multiplicities, regardless of order.

## TypeScript interface

`isAnagram(s: string, t: string): boolean`

## Example

`s = "racecar", t = "carrace" → true`

## Rules

The strings contain lowercase English letters.

Source: [NeetCode problem](https://neetcode.io/problems/is-anagram/)
