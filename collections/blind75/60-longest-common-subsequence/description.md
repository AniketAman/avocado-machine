# Longest Common Subsequence (Medium)

**Topic:** 2-D Dynamic Programming · **Difficulty:** Medium

Find the length of the longest sequence obtainable from each string by deleting characters.

## TypeScript interface

`longestCommonSubsequence(text1: string, text2: string): number`

## Example

`text1 = "cat", text2 = "crabt" → 3`

## Rules

Relative order must remain unchanged.

Source: [NeetCode problem](https://neetcode.io/problems/longest-common-subsequence/)
