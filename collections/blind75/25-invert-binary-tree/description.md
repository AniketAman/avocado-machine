# Invert Binary Tree

**Topic:** Trees · **Difficulty:** Easy

Swap left and right children at every node of a binary tree.

## TypeScript interface

`invertTree(root: TreeNode | null): TreeNode | null`

## Example

`[1, 2, 3, 4, 5, 6, 7] → [1, 3, 2, 7, 6, 5, 4]`

## Rules

Return the root of the inverted tree.

Source: [NeetCode problem](https://neetcode.io/problems/invert-a-binary-tree/)
