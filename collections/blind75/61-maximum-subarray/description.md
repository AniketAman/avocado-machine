# Maximum Subarray (Medium)

**Topic:** Greedy · **Difficulty:** Medium

Find the largest sum of a non-empty contiguous subarray.

## TypeScript interface

`maxSubArray(nums: number[]): number`

## Example

`nums = [2, -3, 4, -2, 2, 1, -1, 4] → 8`

## Rules

An all-negative array still has a non-empty answer.

Source: [NeetCode problem](https://neetcode.io/problems/maximum-subarray/)
