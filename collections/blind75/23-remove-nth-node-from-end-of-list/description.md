# Remove Nth Node From End of List (Medium)

**Topic:** Linked List · **Difficulty:** Medium

Remove the nth node counted from the tail and return the possibly new head.

## TypeScript interface

`removeNthFromEnd(head: ListNode | null, n: number): ListNode | null`

## Example

`[1, 2, 3, 4], n = 2 → [1, 2, 4]`

## Rules

n is between 1 and the list length.

Source: [NeetCode problem](https://neetcode.io/problems/remove-node-from-end-of-linked-list/)
