# Reorder List

**Topic:** Linked List · **Difficulty:** Medium

Rewire a singly linked list from first, last, second, second-last, and so on.

## TypeScript interface

`reorderList(head: ListNode | null): void`

## Example

`[2, 4, 6, 8, 10] → [2, 10, 4, 8, 6]`

## Rules

Modify node links in place; do not replace node values.

Source: [NeetCode problem](https://neetcode.io/problems/reorder-linked-list/)
