# Construct Binary Tree From Preorder And Inorder Traversal (Medium)

**Topic:** Trees · **Difficulty:** Medium

Reconstruct a binary tree from its preorder and inorder value sequences.

## TypeScript interface

`buildTree(preorder: number[], inorder: number[]): TreeNode | null`

## Example

`preorder = [1, 2, 3, 4], inorder = [2, 1, 3, 4] → [1, 2, 3, null, null, null, 4]`

## Rules

All node values are unique and both traversals describe the same tree.
