# Kth Smallest Element In a Bst

**Topic:** Trees · **Difficulty:** Medium

Return the kth smallest BST value, counting from one.

## TypeScript interface

`kthSmallest(root: TreeNode | null, k: number): number`

## Example

`root = [2, 1, 3], k = 1 → 1`

## Rules

k is valid for the given tree.

Source: [NeetCode problem](https://neetcode.io/problems/kth-smallest-integer-in-bst/)
