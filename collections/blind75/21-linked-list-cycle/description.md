# Linked List Cycle (Easy)

**Topic:** Linked List · **Difficulty:** Easy

Report whether following next pointers can revisit a node.

## TypeScript interface

`hasCycle(head: ListNode | null): boolean`

## Example

`[1, 2, 3, 4] with tail linked to node 1 → true`

## Rules

The cycle entry index is used only to build tests; it is not passed to your function.

Source: [NeetCode problem](https://neetcode.io/problems/linked-list-cycle-detection/)
