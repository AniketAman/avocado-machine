# Number of 1 Bits (Easy)

**Topic:** Bit Manipulation · **Difficulty:** Easy

Count set bits in the unsigned 32-bit representation of n.

## TypeScript interface

`hammingWeight(n: number): number`

## Example

`n = 23 → 4`

## Rules

Treat n as a nonnegative 32-bit integer.

Source: [NeetCode problem](https://neetcode.io/problems/number-of-one-bits/)
