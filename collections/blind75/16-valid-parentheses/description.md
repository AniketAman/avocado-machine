# Valid Parentheses (Easy)

**Topic:** Stack · **Difficulty:** Easy

Check that every opening bracket is closed by the matching kind in correctly nested order.

## TypeScript interface

`isValid(s: string): boolean`

## Example

`s = "([{}])" → true`

## Rules

The input contains only (), [], and {} brackets.

Source: [NeetCode problem](https://neetcode.io/problems/validate-parentheses/)
