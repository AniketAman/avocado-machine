# 3Sum

**Topic:** Two Pointers · **Difficulty:** Medium

Find every distinct value triplet from three different indices whose sum is zero.

## TypeScript interface

`threeSum(nums: number[]): number[][]`

## Example

`nums = [-1, 0, 1, 2, -1, -4] → [[-1, -1, 2], [-1, 0, 1]]`

## Rules

Do not return duplicate triplets; order does not matter.

Source: [NeetCode problem](https://neetcode.io/problems/three-integer-sum/)
