# Same Tree

**Topic:** Trees · **Difficulty:** Easy

Determine whether two binary trees have identical shapes and values.

## TypeScript interface

`isSameTree(p: TreeNode | null, q: TreeNode | null): boolean`

## Example

`[1, 2, 3] and [1, 2, 3] → true`

## Rules

Different child positions make trees different even when values match.

Source: [NeetCode problem](https://neetcode.io/problems/same-binary-tree/)
