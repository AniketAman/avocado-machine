# Merge Intervals

**Topic:** Intervals · **Difficulty:** Medium

Merge all overlapping closed intervals.

## TypeScript interface

`merge(intervals: number[][]): number[][]`

## Example

`intervals = [[1, 2], [2, 3]] → [[1, 3]]`

## Rules

Output order is free. Closed intervals sharing an endpoint overlap.

Source: [NeetCode problem](https://neetcode.io/problems/merge-intervals/)
