# Climbing Stairs

**Topic:** 1-D Dynamic Programming · **Difficulty:** Easy

Count the ways to reach step n by taking one or two steps at a time.

## TypeScript interface

`climbStairs(n: number): number`

## Example

`n = 3 → 3`

## Rules

The order of step sizes matters; 1 ≤ n ≤ 45.

Source: [NeetCode problem](https://neetcode.io/problems/climbing-stairs/)
