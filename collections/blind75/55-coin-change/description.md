# Coin Change (Medium)

**Topic:** 1-D Dynamic Programming · **Difficulty:** Medium

Find the fewest coins needed to make amount using unlimited copies of each denomination.

## TypeScript interface

`coinChange(coins: number[], amount: number): number`

## Example

`coins = [1, 5, 10], amount = 12 → 3`

## Rules

Return -1 when impossible and 0 for amount 0.

Source: [NeetCode problem](https://neetcode.io/problems/coin-change/)
