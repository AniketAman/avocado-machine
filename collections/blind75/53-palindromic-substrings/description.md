# Palindromic Substrings (Medium)

**Topic:** 1-D Dynamic Programming · **Difficulty:** Medium

Count palindromic substrings by position.

## TypeScript interface

`countSubstrings(s: string): number`

## Example

`s = "aaa" → 6`

## Rules

Equal text at different start or end positions counts separately.

Source: [NeetCode problem](https://neetcode.io/problems/palindromic-substrings/)
