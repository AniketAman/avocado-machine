# House Robber II (Medium)

**Topic:** 1-D Dynamic Programming · **Difficulty:** Medium

Maximize money taken from houses arranged in a circle without taking adjacent houses.

## TypeScript interface

`rob(nums: number[]): number`

## Example

`nums = [3, 4, 3] → 4`

## Rules

The first and last houses are adjacent, except when there is just one house.

Source: [NeetCode problem](https://neetcode.io/problems/house-robber-ii/)
