# Counting Bits

**Topic:** Bit Manipulation · **Difficulty:** Easy

For each integer from 0 through n, return its number of set bits.

## TypeScript interface

`countBits(n: number): number[]`

## Example

`n = 4 → [0, 1, 1, 2, 1]`

## Rules

The output includes the count for zero.

Source: [NeetCode problem](https://neetcode.io/problems/counting-bits/)
