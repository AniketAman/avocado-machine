# Validate Binary Search Tree (Medium)

**Topic:** Trees · **Difficulty:** Medium

Check that every node is strictly greater than all values to its left and strictly less than all values to its right.

## TypeScript interface

`isValidBST(root: TreeNode | null): boolean`

## Example

`[2, 1, 3] → true`

## Rules

Duplicate values are invalid. The rule applies to entire subtrees.
