# Valid Palindrome (Easy)

**Topic:** Two Pointers · **Difficulty:** Easy

Check whether s reads identically forward and backward after ignoring case and non-alphanumeric characters.

## TypeScript interface

`isPalindrome(s: string): boolean`

## Example

`s = "Was it a car or a cat I saw?" → true`

## Rules

Letters A–Z and digits 0–9 count as alphanumeric.

Source: [NeetCode problem](https://neetcode.io/problems/is-palindrome/)
