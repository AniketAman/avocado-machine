# Reverse Bits (Easy)

**Topic:** Bit Manipulation · **Difficulty:** Easy

Reverse all 32 bits of an unsigned integer and return the resulting unsigned value.

## TypeScript interface

`reverseBits(n: number): number`

## Example

`n = 21 → 2818572288`

## Rules

Leading zero bits become trailing zero bits.

Source: [NeetCode problem](https://neetcode.io/problems/reverse-bits/)
