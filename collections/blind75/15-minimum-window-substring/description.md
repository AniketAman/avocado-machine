# Minimum Window Substring (Hard)

**Topic:** Sliding Window · **Difficulty:** Hard

Return the shortest contiguous part of s containing every character of t with the required multiplicity.

## TypeScript interface

`minWindow(s: string, t: string): string`

## Example

`s = "OUZODYXAZV", t = "XYZ" → "YXAZ"`

## Rules

Return an empty string if impossible. The minimum answer is unique.

Source: [NeetCode problem](https://neetcode.io/problems/minimum-window-with-characters/)
