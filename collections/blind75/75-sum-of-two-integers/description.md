# Sum of Two Integers (Medium)

**Topic:** Bit Manipulation · **Difficulty:** Medium

Add two signed integers without using arithmetic + or - operators in the solution.

## TypeScript interface

`getSum(a: number, b: number): number`

## Example

`a = 4, b = 7 → 11`

## Rules

Inputs range from -1000 through 1000.

Source: [NeetCode problem](https://neetcode.io/problems/sum-of-two-integers/)
