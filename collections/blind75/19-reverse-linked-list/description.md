# Reverse Linked List

**Topic:** Linked List · **Difficulty:** Easy

Reverse the links of a singly linked list and return its new head.

## TypeScript interface

`reverseList(head: ListNode | null): ListNode | null`

## Example

`[0, 1, 2, 3] → [3, 2, 1, 0]`

## Rules

An empty list remains empty.

Source: [NeetCode problem](https://neetcode.io/problems/reverse-a-linked-list/)
