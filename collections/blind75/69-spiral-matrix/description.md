# Spiral Matrix (Medium)

**Topic:** Math & Geometry · **Difficulty:** Medium

List matrix values clockwise in a spiral from the upper-left corner toward the center.

## TypeScript interface

`spiralOrder(matrix: number[][]): number[]`

## Example

`[[1, 2], [3, 4]] → [1, 2, 4, 3]`

## Rules

Rectangular matrices are allowed.

Source: [NeetCode problem](https://neetcode.io/problems/spiral-matrix/)
