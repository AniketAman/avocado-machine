# Maximum Product Subarray (Medium)

**Topic:** 1-D Dynamic Programming · **Difficulty:** Medium

Find the largest product of any non-empty contiguous subarray.

## TypeScript interface

`maxProduct(nums: number[]): number`

## Example

`nums = [2, 4, -3, 5] → 8`

## Rules

Negative numbers and zero can change which running product is best.

Source: [NeetCode problem](https://neetcode.io/problems/maximum-product-subarray/)
