# Longest Palindromic Substring (Medium)

**Topic:** 1-D Dynamic Programming · **Difficulty:** Medium

Return a longest contiguous substring that is a palindrome.

## TypeScript interface

`longestPalindrome(s: string): string`

## Example

`s = "abbc" → "bb"`

## Rules

When several longest substrings tie, any one is valid.

Source: [NeetCode problem](https://neetcode.io/problems/longest-palindromic-substring/)
