# Two Sum

**Topic:** Arrays & Hashing · **Difficulty:** Easy

Find the two distinct indices whose values add to target.

## TypeScript interface

`twoSum(nums: number[], target: number): number[]`

## Example

`nums = [3, 4, 5, 6], target = 7 → [0, 1]`

## Rules

Exactly one pair exists. Return the smaller index first.

Source: [NeetCode problem](https://neetcode.io/problems/two-integer-sum/)
