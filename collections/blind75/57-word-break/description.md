# Word Break (Medium)

**Topic:** 1-D Dynamic Programming · **Difficulty:** Medium

Decide whether s can be split into one or more dictionary words.

## TypeScript interface

`wordBreak(s: string, wordDict: string[]): boolean`

## Example

`s = "neetcode", wordDict = ["neet", "code"] → true`

## Rules

Dictionary words may be reused.

Source: [NeetCode problem](https://neetcode.io/problems/word-break/)
