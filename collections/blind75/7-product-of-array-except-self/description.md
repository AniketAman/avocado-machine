# Product of Array Except Self

**Topic:** Arrays & Hashing · **Difficulty:** Medium

For each index, multiply every array element except the one at that index.

## TypeScript interface

`productExceptSelf(nums: number[]): number[]`

## Example

`nums = [1, 2, 4, 6] → [48, 24, 12, 8]`

## Rules

Handle zeroes and negative values. Aim for linear time without division.

Source: [NeetCode problem](https://neetcode.io/problems/products-of-array-discluding-self/)
