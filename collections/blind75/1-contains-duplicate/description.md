# Contains Duplicate (Easy)

**Topic:** Arrays & Hashing · **Difficulty:** Easy

Decide whether any integer appears at least twice in nums.

## TypeScript interface

`containsDuplicate(nums: number[]): boolean`

## Example

`nums = [1, 2, 3, 3] → true`

## Rules

An empty array has no duplicate.

Source: [NeetCode problem](https://neetcode.io/problems/duplicate-integer/)
