# Permutations (Medium)

**Topic:** Recursion · **Difficulty:** Medium

Return every ordering of the distinct integers in the input array.

## TypeScript interface

`permute(nums: number[]): number[][]`

## Example

`[1, 2] → [[1, 2], [2, 1]]`

## Rules

Each permutation must use every input value exactly once. Result order is unrestricted.

Source: [LeetCode problem](https://leetcode.com/problems/permutations/)
