# Minimum Height Trees (Medium)

**Topic:** Graph · **Difficulty:** Medium

Choose every possible root that minimizes the height of an undirected tree.

## TypeScript interface

`findMinHeightTrees(n: number, edges: number[][]): number[]`

## Example

`n=4, edges=[[1,0],[1,2],[1,3]] → [1]`

## Rules

Nodes are numbered `0` through `n-1`. Return all best roots in any order.

Source: [LeetCode problem](https://leetcode.com/problems/minimum-height-trees/)
