# Sort Colors (Medium)

**Topic:** Array · **Difficulty:** Medium

Rearrange an array containing only 0, 1, and 2 so equal values are together in ascending order.

## TypeScript interface

`sortColors(nums: number[]): void`

## Example

`[2, 0, 2, 1, 1, 0] → [0, 0, 1, 1, 2, 2]`

## Rules

Modify the input array in place; do not return a replacement array.

Source: [LeetCode problem](https://leetcode.com/problems/sort-colors/)
