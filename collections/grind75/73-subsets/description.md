# Subsets (Medium)

**Topic:** Recursion · **Difficulty:** Medium

Return every subset of a set of distinct integers.

## TypeScript interface

`subsets(nums: number[]): number[][]`

## Example

`[1, 2] → [[], [1], [2], [1, 2]]`

## Rules

Include the empty set and full set. Subset and result order are unrestricted.

Source: [LeetCode problem](https://leetcode.com/problems/subsets/)
