# Find All Anagrams in a String (Medium)

**Topic:** String · **Difficulty:** Medium

Find every starting index where a substring of `s` is an anagram of `p`.

## TypeScript interface

`findAnagrams(s: string, p: string): number[]`

## Example

`s = "cbaebabacd", p = "abc" → [0, 6]`

## Rules

Both strings contain lowercase English letters. Return indices in ascending order.

Source: [LeetCode problem](https://leetcode.com/problems/find-all-anagrams-in-a-string/)
