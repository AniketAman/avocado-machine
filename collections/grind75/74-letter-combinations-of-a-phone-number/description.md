# Letter Combinations of a Phone Number (Medium)

**Topic:** Recursion · **Difficulty:** Medium

Return all letter strings represented by digits on a telephone keypad.

## TypeScript interface

`letterCombinations(digits: string): string[]`

## Example

`"23" → ["ad", "ae", "af", "bd", "be", "bf", "cd", "ce", "cf"]`

## Rules

Digits are from `2` through `9`. Return an empty array for empty input; order is unrestricted.

Source: [LeetCode problem](https://leetcode.com/problems/letter-combinations-of-a-phone-number/)
