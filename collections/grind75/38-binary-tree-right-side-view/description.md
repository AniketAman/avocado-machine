# Binary Tree Right Side View (Medium)

**Topic:** Binary Tree · **Difficulty:** Medium

Return the node value visible from the right at each depth of a binary tree.

## TypeScript interface

`rightSideView(root: TreeNode | null): number[]`

## Example

`[1, 2, 3, null, 5, null, 4] → [1, 3, 4]`

## Rules

Return values from top level to bottom. An empty tree yields an empty array.
