# Longest Palindrome (Easy)

**Topic:** String · **Difficulty:** Easy

Return the greatest length of a palindrome that can be built from the supplied letters.

## TypeScript interface

`longestPalindrome(s: string): number`

## Example

`"abccccdd" → 7`

## Rules

You may rearrange letters. Uppercase and lowercase letters count as distinct.

Source: [LeetCode problem](https://leetcode.com/problems/longest-palindrome/)
