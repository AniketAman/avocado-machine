# Binary Search (Easy)

**Topic:** Binary Search · **Difficulty:** Easy

Find a target value in a sorted array of distinct integers.

## TypeScript interface

`search(nums: number[], target: number): number`

## Example

`[-1, 0, 3, 5, 9, 12], target = 9 → 4`

## Rules

Return `-1` if absent. Use logarithmic time.

Source: [LeetCode problem](https://leetcode.com/problems/binary-search/)
