# Trapping Rain Water (Hard)

**Topic:** Stack · **Difficulty:** Hard

Given the height of adjacent unit-width bars, compute the total water held between them after rain.

## TypeScript interface

`trap(height: number[]): number`

## Example

`[0, 1, 0, 2, 1, 0, 1, 3] → 5`

## Rules

Heights are nonnegative integers.

Source: [LeetCode problem](https://leetcode.com/problems/trapping-rain-water/)
