# Middle of the Linked List (Easy)

**Topic:** Linked List · **Difficulty:** Easy

Return the middle node of a singly linked list.

## TypeScript interface

`middleNode(head: ListNode | null): ListNode | null`

## Example

`1 → 2 → 3 → 4 → 5` returns the node holding `3`.

## Rules

When there are two middle nodes, return the second. Return `null` for an empty list.
