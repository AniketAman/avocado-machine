# Balanced Binary Tree (Easy)

**Topic:** Binary Tree · **Difficulty:** Easy

Decide whether every node of a binary tree has left and right subtree heights differing by at most one.

## TypeScript interface

`isBalanced(root: TreeNode | null): boolean`

## Example

`[3, 9, 20, null, null, 15, 7] → true`

## Rules

An empty tree is balanced.

Source: [LeetCode problem](https://leetcode.com/problems/balanced-binary-tree/)
