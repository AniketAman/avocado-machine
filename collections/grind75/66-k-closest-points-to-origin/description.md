# K Closest Points to Origin (Medium)

**Topic:** Heap · **Difficulty:** Medium

Return the `k` two-dimensional points with the smallest squared distance from the origin.

## TypeScript interface

`kClosest(points: number[][], k: number): number[][]`

## Example

`points=[[1,3],[-2,2]], k=1 → [[-2,2]]`

## Rules

Return the chosen points in any order. Each point is `[x, y]`.

Source: [LeetCode problem](https://leetcode.com/problems/k-closest-points-to-origin/)
