# Basic Calculator (Hard)

**Topic:** Stack · **Difficulty:** Hard

Evaluate an expression containing integers, spaces, parentheses, plus signs, and minus signs.

## TypeScript interface

`calculate(expression: string): number`

## Example

`"1 + (2 - 3)" → 0`

## Rules

Unary minus is allowed. Do not use `eval` or a similar expression interpreter.

Source: [LeetCode problem](https://leetcode.com/problems/basic-calculator/)
