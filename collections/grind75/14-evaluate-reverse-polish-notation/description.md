# Evaluate Reverse Polish Notation (Medium)

**Topic:** Stack · **Difficulty:** Medium

Evaluate an arithmetic expression given as tokens in postfix order.

## TypeScript interface

`evalRPN(tokens: string[]): number`

## Example

`["2", "1", "+", "3", "*"] → 9`

## Rules

Operators are `+`, `-`, `*`, and `/`. Division truncates toward zero. Every expression is valid.

Source: [LeetCode problem](https://leetcode.com/problems/evaluate-reverse-polish-notation/)
