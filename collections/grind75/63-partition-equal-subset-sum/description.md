# Partition Equal Subset Sum (Medium)

**Topic:** Dynamic Programming · **Difficulty:** Medium

Decide whether the array can be split into two subsets with equal sums.

## TypeScript interface

`canPartition(nums: number[]): boolean`

## Example

`[1, 5, 11, 5] → true`

## Rules

Every number is a positive integer; each array element belongs to exactly one subset.

Source: [LeetCode problem](https://leetcode.com/problems/partition-equal-subset-sum/)
