# Majority Element (Easy)

**Topic:** Array · **Difficulty:** Easy

Return the value that appears more than half the time in a nonempty integer array.

## TypeScript interface

`majorityElement(nums: number[]): number`

## Example

`[2, 2, 1, 2] → 2`

## Rules

A majority value is guaranteed to exist.

Source: [LeetCode problem](https://leetcode.com/problems/majority-element/)
