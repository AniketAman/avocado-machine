# Diameter of Binary Tree (Easy)

**Topic:** Binary Tree · **Difficulty:** Easy

Find the maximum number of edges on any path between two nodes in a binary tree.

## TypeScript interface

`diameterOfBinaryTree(root: TreeNode | null): number`

## Example

`[1, 2, 3, 4, 5] → 3`

## Rules

The path need not pass through the root. An empty or single-node tree has diameter 0.

Source: [LeetCode problem](https://leetcode.com/problems/diameter-of-binary-tree/)
