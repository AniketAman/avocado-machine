# Add Binary (Easy)

**Topic:** Binary · **Difficulty:** Easy

Add two nonnegative integers represented as binary strings.

## TypeScript interface

`addBinary(a: string, b: string): string`

## Example

`"11" + "1" → "100"`

## Rules

Return a binary string without extra leading zeros. Each input is nonempty.

Source: [LeetCode problem](https://leetcode.com/problems/add-binary/)
