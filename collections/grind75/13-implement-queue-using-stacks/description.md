# Implement Queue using Stacks (Easy)

**Topic:** Stack · **Difficulty:** Easy

Build a first-in, first-out queue using stack operations.

## TypeScript interface

`class MyQueue { push(x: number): void; pop(): number; peek(): number; empty(): boolean }`

## Example

`push(1), push(2), peek() → 1, pop() → 1, empty() → false`

## Rules

`pop` and `peek` are called only while the queue is nonempty.
