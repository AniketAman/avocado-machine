# Largest Rectangle in Histogram (Hard)

**Topic:** Stack · **Difficulty:** Hard

Find the largest rectangle that fits beneath adjacent unit-width histogram bars.

## TypeScript interface

`largestRectangleArea(heights: number[]): number`

## Example

`[2, 1, 5, 6, 2, 3] → 10`

## Rules

Bar heights are nonnegative integers.

Source: [LeetCode problem](https://leetcode.com/problems/largest-rectangle-in-histogram/)
