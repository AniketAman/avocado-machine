# Ransom Note (Easy)

**Topic:** Hash Table · **Difficulty:** Easy

Decide whether the letters in a magazine can supply all letters needed for a ransom note.

## TypeScript interface

`canConstruct(ransomNote: string, magazine: string): boolean`

## Example

`"aa", "aab" → true`

## Rules

A magazine letter can be used at most once. Both strings contain lowercase English letters.

Source: [LeetCode problem](https://leetcode.com/problems/ransom-note/)
