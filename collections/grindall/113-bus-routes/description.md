# Graph: Bus Routes (Hard)

**Topic:** Graph | **Difficulty:** Hard

Return the minimum buses needed to travel between stops, or -1 when no route connects them.

## TypeScript interface

`solve(routes: number[][], source: number, target: number): number`

## Examples

- Input: `[[[1,2,7],[3,6,7]],1,6]`; output: `2`.
- Input: `[[[1,2,7]],1,1]`; output: `0`.
- Input: `[[[1,2],[3,4]],1,4]`; output: `-1`.

Source: [LeetCode problem](https://leetcode.com/problems/bus-routes/)
