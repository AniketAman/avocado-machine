# Linked List: Reverse Nodes in k-Group (Hard)

**Topic:** Linked List | **Difficulty:** Hard

Reverse each complete group of k list nodes; leave the final shorter group unchanged.

## TypeScript interface

`solve(head: ListNode | null, k: number): ListNode | null`

## Examples

- Input: `[[1,2,3,4,5],2]`; output: `[2,1,4,3,5]`.
- Input: `[[1,2,3,4,5],3]`; output: `[3,2,1,4,5]`.

Source: [LeetCode problem](https://leetcode.com/problems/reverse-nodes-in-k-group/)
