# Array: Squares of a Sorted Array (Easy)

**Topic:** Array | **Difficulty:** Easy

Return the squares of a nondecreasing array in nondecreasing order.

## TypeScript interface

`solve(nums: number[]): number[]`

## Examples

- Input: `[-4,-1,0,3,10]`; output: `[0,1,9,16,100]`.
- Input: `[-7,-3,2,3,11]`; output: `[4,9,9,49,121]`.

Source: [LeetCode problem](https://leetcode.com/problems/squares-of-a-sorted-array/)
