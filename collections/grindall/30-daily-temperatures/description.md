# Stack: Daily Temperatures (Medium)

**Topic:** Stack | **Difficulty:** Medium

For each day, return how many days until a warmer temperature, or zero if none occurs.

## TypeScript interface

`solve(temperatures: number[]): number[]`

## Examples

- Input: `[73,74,75,71,69,72,76,73]`; output: `[1,1,4,2,1,1,0,0]`.
- Input: `[30,40,50,60]`; output: `[1,1,1,0]`.

Source: [LeetCode problem](https://leetcode.com/problems/daily-temperatures/)
