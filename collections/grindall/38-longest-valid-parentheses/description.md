# Stack: Longest Valid Parentheses (Hard)

**Topic:** Stack | **Difficulty:** Hard

Return the length of the longest well-formed parentheses substring.

## TypeScript interface

`solve(s: string): number`

## Examples

- Input: `"(()"`; output: `2`.
- Input: `")()())"`; output: `4`.
- Input: `""`; output: `0`.

Source: [LeetCode problem](https://leetcode.com/problems/longest-valid-parentheses/)
