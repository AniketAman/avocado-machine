# Binary Search: Search a 2D Matrix (Medium)

**Topic:** Binary Search | **Difficulty:** Medium

Search a matrix whose rows increase and whose next row starts above the previous row's last value.

## TypeScript interface

`solve(matrix: number[][], target: number): boolean`

## Examples

- Input: `[[[1,3,5,7],[10,11,16,20],[23,30,34,60]],3]`; output: `true`.
- Input: `[[[1,3,5,7],[10,11,16,20]],13]`; output: `false`.

Source: [LeetCode problem](https://leetcode.com/problems/search-a-2d-matrix/)
