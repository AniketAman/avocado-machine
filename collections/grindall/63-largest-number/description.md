# String: Largest Number (Medium)

**Topic:** String | **Difficulty:** Medium

Arrange nonnegative integers so their concatenation forms the largest possible decimal number.

## TypeScript interface

`solve(nums: number[]): string`

## Examples

- Input: `[10,2]`; output: `"210"`.
- Input: `[3,30,34,5,9]`; output: `"9534330"`.
- Input: `[0,0]`; output: `"0"`.

Source: [LeetCode problem](https://leetcode.com/problems/largest-number/)
