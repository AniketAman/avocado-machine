# Array: Sliding Window Maximum (Hard)

**Topic:** Array | **Difficulty:** Hard

Return the maximum value in every contiguous window of size k.

## TypeScript interface

`solve(nums: number[], k: number): number[]`

## Examples

- Input: `[[1,3,-1,-3,5,3,6,7],3]`; output: `[3,3,5,5,6,7]`.
- Input: `[[1],1]`; output: `[1]`.

Source: [LeetCode problem](https://leetcode.com/problems/sliding-window-maximum/)
