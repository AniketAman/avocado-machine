# Array: Subarray Sum Equals K (Medium)

**Topic:** Array | **Difficulty:** Medium

Count contiguous subarrays whose elements sum to k.

## TypeScript interface

`solve(nums: number[], k: number): number`

## Examples

- Input: `[[1,1,1],2]`; output: `2`.
- Input: `[[1,2,3],3]`; output: `2`.
- Input: `[[0,0,0],0]`; output: `6`.

Source: [LeetCode problem](https://leetcode.com/problems/subarray-sum-equals-k/)
