# Graph: Shortest Path to Get Food (Medium)

**Topic:** Graph | **Difficulty:** Medium

From the cell marked *, find the fewest moves to any food cell # through open cells O; X cells are blocked.

## TypeScript interface

`solve(grid: string[][]): number`

## Examples

- Input: `[["X","X","X","X"],["X","*","O","X"],["X","O","#","X"],["X","X","X","X"]]`; output: `2`.
- Input: `[["*","X","#"]]`; output: `-1`.
