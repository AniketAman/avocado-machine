# Recursion: Next Permutation (Medium)

**Topic:** Recursion | **Difficulty:** Medium

Rearrange the array in place into its next lexicographic permutation, wrapping to the smallest permutation.

## TypeScript interface

`solve(nums: number[]): void`

## Examples

- Input: `[1,2,3]`; output: `[1,3,2]`.
- Input: `[3,2,1]`; output: `[1,2,3]`.
- Input: `[1,1,5]`; output: `[1,5,1]`.

Source: [LeetCode problem](https://leetcode.com/problems/next-permutation/)
