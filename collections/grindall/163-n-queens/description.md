# Recursion: N-Queens (Hard)

**Topic:** Recursion | **Difficulty:** Hard

Return all placements of n queens on an n-by-n board with no two queens sharing a row, column, or diagonal.

## TypeScript interface

`solve(n: number): string[][]`

## Examples

- Input: `1`; output: `[["Q"]]`.

Source: [LeetCode problem](https://leetcode.com/problems/n-queens/)
