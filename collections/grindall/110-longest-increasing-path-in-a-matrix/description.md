# Graph: Longest Increasing Path in a Matrix (Hard)

**Topic:** Graph | **Difficulty:** Hard

Return the length of the longest strictly increasing path using orthogonal moves in a matrix.

## TypeScript interface

`solve(matrix: number[][]): number`

## Examples

- Input: `[[9,9,4],[6,6,8],[2,1,1]]`; output: `4`.
- Input: `[[3,4,5],[3,2,6],[2,2,1]]`; output: `4`.

Source: [LeetCode problem](https://leetcode.com/problems/longest-increasing-path-in-a-matrix/)
