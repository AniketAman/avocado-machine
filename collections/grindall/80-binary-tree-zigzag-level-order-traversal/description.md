# Binary Tree: Binary Tree Zigzag Level Order Traversal (Medium)

**Topic:** Binary Tree | **Difficulty:** Medium

Return tree values level by level, alternating left-to-right and right-to-left order.

## TypeScript interface

`solve(root: TreeNode | null): number[][]`

## Examples

- Input: `[3,9,20,null,null,15,7]`; output: `[[3],[20,9],[15,7]]`.
- Input: `[1]`; output: `[[1]]`.

Source: [LeetCode problem](https://leetcode.com/problems/binary-tree-zigzag-level-order-traversal/)
