# Array: 3Sum Closest (Medium)

**Topic:** Array | **Difficulty:** Medium

Return the sum of three distinct elements closest to target; exactly one best answer exists.

## TypeScript interface

`solve(nums: number[], target: number): number`

## Examples

- Input: `[[-1,2,1,-4],1]`; output: `2`.
- Input: `[[0,0,0],1]`; output: `0`.

Source: [LeetCode problem](https://leetcode.com/problems/3sum-closest/)
