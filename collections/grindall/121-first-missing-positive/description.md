# Hash Table: First Missing Positive (Hard)

**Topic:** Hash Table | **Difficulty:** Hard

Return the smallest positive integer absent from an unsorted array.

## TypeScript interface

`solve(nums: number[]): number`

## Examples

- Input: `[1,2,0]`; output: `3`.
- Input: `[3,4,-1,1]`; output: `2`.
- Input: `[7,8,9,11,12]`; output: `1`.

Source: [LeetCode problem](https://leetcode.com/problems/first-missing-positive/)
