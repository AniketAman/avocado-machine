# Graph: Minimum Knight Moves (Medium)

**Topic:** Graph | **Difficulty:** Medium

Find the fewest chess-knight moves from (0, 0) to (x, y) on an infinite board.

## TypeScript interface

`solve(x: number, y: number): number`

## Examples

- Input: `[2,1]`; output: `1`.
- Input: `[5,5]`; output: `4`.
- Input: `[0,0]`; output: `0`.

Source: [LeetCode problem](https://leetcode.com/problems/minimum-knight-moves/)
