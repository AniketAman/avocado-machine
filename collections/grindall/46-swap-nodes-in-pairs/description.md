# Linked List: Swap Nodes in Pairs (Medium)

**Topic:** Linked List | **Difficulty:** Medium

Swap adjacent list nodes in pairs and return the new head.

## TypeScript interface

`solve(head: ListNode | null): ListNode | null`

## Examples

- Input: `[1,2,3,4]`; output: `[2,1,4,3]`.
- Input: `[1,2,3]`; output: `[2,1,3]`.
- Input: `[]`; output: `[]`.

Source: [LeetCode problem](https://leetcode.com/problems/swap-nodes-in-pairs/)
