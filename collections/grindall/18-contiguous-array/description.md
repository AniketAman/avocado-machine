# Array: Contiguous Array (Medium)

**Topic:** Array | **Difficulty:** Medium

Return the length of the longest contiguous subarray containing equal numbers of zeroes and ones.

## TypeScript interface

`solve(nums: number[]): number`

## Examples

- Input: `[0,1]`; output: `2`.
- Input: `[0,1,0]`; output: `2`.
- Input: `[0,0,1,1,0,1]`; output: `6`.

Source: [LeetCode problem](https://leetcode.com/problems/contiguous-array/)
