# Math: Reverse Integer (Medium)

**Topic:** Math | **Difficulty:** Medium

Reverse the decimal digits of a signed 32-bit integer; return zero on overflow.

## TypeScript interface

`solve(x: number): number`

## Examples

- Input: `123`; output: `321`.
- Input: `-123`; output: `-321`.
- Input: `1534236469`; output: `0`.

Source: [LeetCode problem](https://leetcode.com/problems/reverse-integer/)
