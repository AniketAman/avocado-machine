# Math: Palindrome Number (Easy)

**Topic:** Math | **Difficulty:** Easy

Determine whether an integer reads the same from both ends in decimal notation.

## TypeScript interface

`solve(x: number): boolean`

## Examples

- Input: `121`; output: `true`.
- Input: `-121`; output: `false`.
- Input: `10`; output: `false`.

Source: [LeetCode problem](https://leetcode.com/problems/palindrome-number/)
