# Linked List: Add Two Numbers (Medium)

**Topic:** Linked List | **Difficulty:** Medium

Add two nonnegative integers represented by reverse-order linked-list digits and return reverse-order digits.

## TypeScript interface

`solve(l1: ListNode | null, l2: ListNode | null): ListNode | null`

## Examples

- Input: `[[2,4,3],[5,6,4]]`; output: `[7,0,8]`.
- Input: `[[9,9,9],[1]]`; output: `[0,0,0,1]`.

Source: [LeetCode problem](https://leetcode.com/problems/add-two-numbers/)
