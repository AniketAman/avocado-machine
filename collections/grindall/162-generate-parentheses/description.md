# Recursion: Generate Parentheses (Medium)

**Topic:** Recursion | **Difficulty:** Medium

Generate every well-formed string made from n pairs of parentheses.

## TypeScript interface

`solve(n: number): string[]`

## Examples

- Input: `1`; output: `["()"]`.
- Input: `3`; output: `["((()))","(()())","(())()","()(())","()()()"]`.

Source: [LeetCode problem](https://leetcode.com/problems/generate-parentheses/)
