# Stack: Backspace String Compare (Easy)

**Topic:** Stack | **Difficulty:** Easy

Compare the final strings produced when # deletes the preceding character.

## TypeScript interface

`solve(s: string, t: string): boolean`

## Examples

- Input: `["ab#c","ad#c"]`; output: `true`.
- Input: `["a#c","b"]`; output: `false`.
- Input: `["xywrrmp","xywrrmu#p"]`; output: `true`.

Source: [LeetCode problem](https://leetcode.com/problems/backspace-string-compare/)
