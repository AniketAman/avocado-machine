# Math: Pow(x, n) (Medium)

**Topic:** Math | **Difficulty:** Medium

Compute x raised to integer power n, including negative exponents.

## TypeScript interface

`solve(x: number, n: number): number`

## Examples

- Input: `[2,10]`; output: `1024`.
- Input: `[2,-2]`; output: `0.25`.
- Input: `[2.1,3]`; output: `9.261000000000001`.

Source: [LeetCode problem](https://leetcode.com/problems/powx-n/)
