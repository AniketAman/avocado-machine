# Binary Search: Median of Two Sorted Arrays (Hard)

**Topic:** Binary Search | **Difficulty:** Hard

Return the median of two individually sorted arrays in O(log(m+n)) time.

## TypeScript interface

`solve(nums1: number[], nums2: number[]): number`

## Examples

- Input: `[[1,3],[2]]`; output: `2`.
- Input: `[[1,2],[3,4]]`; output: `2.5`.

Source: [LeetCode problem](https://leetcode.com/problems/median-of-two-sorted-arrays/)
