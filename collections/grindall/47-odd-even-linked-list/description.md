# Linked List: Odd Even Linked List (Medium)

**Topic:** Linked List | **Difficulty:** Medium

Group nodes in odd positions before nodes in even positions while keeping each group in order.

## TypeScript interface

`solve(head: ListNode | null): ListNode | null`

## Examples

- Input: `[1,2,3,4,5]`; output: `[1,3,5,2,4]`.
- Input: `[2,1,3,5,6,4,7]`; output: `[2,3,6,7,1,5,4]`.

Source: [LeetCode problem](https://leetcode.com/problems/odd-even-linked-list/)
