# Dynamic Programming: Combination Sum IV (Medium)

**Topic:** Dynamic Programming | **Difficulty:** Medium

Count ordered sequences of values from nums that add up to target; values may be reused.

## TypeScript interface

`solve(nums: number[], target: number): number`

## Examples

- Input: `[[1,2,3],4]`; output: `7`.
- Input: `[[9],3]`; output: `0`.
