# Binary: Single Number (Easy)

**Topic:** Binary | **Difficulty:** Easy

Every element occurs twice except one; return the element occurring once.

## TypeScript interface

`solve(nums: number[]): number`

## Examples

- Input: `[2,2,1]`; output: `1`.
- Input: `[4,1,2,1,2]`; output: `4`.

Source: [LeetCode problem](https://leetcode.com/problems/single-number/)
