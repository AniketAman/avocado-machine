# Heap: Top K Frequent Words (Medium)

**Topic:** Heap | **Difficulty:** Medium

Return the k most frequent words, breaking frequency ties by lexicographic order.

## TypeScript interface

`solve(words: string[], k: number): string[]`

## Examples

- Input: `[["i","love","leetcode","i","love","coding"],2]`; output: `["i","love"]`.
- Input: `[["the","day","is","sunny","the","the","the","sunny","is","is"],4]`; output: `["the","is","sunny","day"]`.

Source: [LeetCode problem](https://leetcode.com/problems/top-k-frequent-words/)
