# Stack: Basic Calculator II (Medium)

**Topic:** Stack | **Difficulty:** Medium

Evaluate +, -, *, and / in a nonnegative integer expression using normal precedence; division truncates toward zero.

## TypeScript interface

`solve(s: string): number`

## Examples

- Input: `"3+2*2"`; output: `7`.
- Input: `" 3/2 "`; output: `1`.
- Input: `" 3+5 / 2 "`; output: `5`.

Source: [LeetCode problem](https://leetcode.com/problems/basic-calculator-ii/)
