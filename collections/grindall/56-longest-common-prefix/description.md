# String: Longest Common Prefix (Easy)

**Topic:** String | **Difficulty:** Easy

Return the longest prefix shared by every string, or an empty string when none exists.

## TypeScript interface

`solve(words: string[]): string`

## Examples

- Input: `["flower","flow","flight"]`; output: `"fl"`.
- Input: `["dog","racecar","car"]`; output: `""`.

Source: [LeetCode problem](https://leetcode.com/problems/longest-common-prefix/)
