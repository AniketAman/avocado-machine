# Array: Employee Free Time (Hard)

**Topic:** Array | **Difficulty:** Hard

Given each employee's sorted, disjoint [start, end] work intervals, return finite intervals when everyone is free.

## TypeScript interface

`solve(schedule: number[][][]): number[][]`

## Examples

- Input: `[[[1,2],[5,6]],[[1,3]],[[4,10]]]`; output: `[[3,4]]`.
- Input: `[[[1,3],[6,7]],[[2,4]],[[2,5],[9,12]]]`; output: `[[5,6],[7,9]]`.

Source: [LeetCode problem](https://leetcode.com/problems/employee-free-time/)
