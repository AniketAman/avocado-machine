# Heap: Smallest Range Covering Elements from K Lists (Hard)

**Topic:** Heap | **Difficulty:** Hard

Find the shortest inclusive range containing at least one value from each sorted list; break ties by lower start.

## TypeScript interface

`solve(nums: number[][]): number[]`

## Examples

- Input: `[[4,10,15,24,26],[0,9,12,20],[5,18,22,30]]`; output: `[20,24]`.
- Input: `[[1,2,3],[1,2,3],[1,2,3]]`; output: `[1,1]`.

Source: [LeetCode problem](https://leetcode.com/problems/smallest-range-covering-elements-from-k-lists/)
