# Binary Tree: Symmetric Tree (Easy)

**Topic:** Binary Tree | **Difficulty:** Easy

Determine whether a binary tree is a mirror of itself around its center.

## TypeScript interface

`solve(root: TreeNode | null): boolean`

## Examples

- Input: `[1,2,2,3,4,4,3]`; output: `true`.
- Input: `[1,2,2,null,3,null,3]`; output: `false`.

Source: [LeetCode problem](https://leetcode.com/problems/symmetric-tree/)
