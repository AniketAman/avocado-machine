# Stack: Decode String (Medium)

**Topic:** Stack | **Difficulty:** Medium

Decode nested repetition groups written as k[encoded_string].

## TypeScript interface

`solve(s: string): string`

## Examples

- Input: `"3[a]2[bc]"`; output: `"aaabcbc"`.
- Input: `"3[a2[c]]"`; output: `"accaccacc"`.
- Input: `"2[abc]3[cd]ef"`; output: `"abcabccdcdcdef"`.

Source: [LeetCode problem](https://leetcode.com/problems/decode-string/)
