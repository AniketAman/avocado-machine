# Binary: Find the Duplicate Number (Medium)

**Topic:** Binary | **Difficulty:** Medium

An array of n+1 integers in [1,n] contains one repeated value; find it without modifying the array.

## TypeScript interface

`solve(nums: number[]): number`

## Examples

- Input: `[1,3,4,2,2]`; output: `2`.
- Input: `[3,1,3,4,2]`; output: `3`.

Source: [LeetCode problem](https://leetcode.com/problems/find-the-duplicate-number/)
