# String: Palindrome Pairs (Hard)

**Topic:** String | **Difficulty:** Hard

Return all ordered pairs of distinct indices whose concatenated words form a palindrome.

## TypeScript interface

`solve(words: string[]): number[][]`

## Examples

- Input: `["bat","tab","cat"]`; output: `[[0,1],[1,0]]`.
- Input: `["a",""]`; output: `[[0,1],[1,0]]`.

Source: [LeetCode problem](https://leetcode.com/problems/palindrome-pairs/)
