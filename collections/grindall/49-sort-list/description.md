# Linked List: Sort List (Medium)

**Topic:** Linked List | **Difficulty:** Medium

Sort a singly linked list in ascending order.

## TypeScript interface

`solve(head: ListNode | null): ListNode | null`

## Examples

- Input: `[4,2,1,3]`; output: `[1,2,3,4]`.
- Input: `[-1,5,3,4,0]`; output: `[-1,0,3,4,5]`.

Source: [LeetCode problem](https://leetcode.com/problems/sort-list/)
