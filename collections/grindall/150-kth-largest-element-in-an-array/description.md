# Heap: Kth Largest Element in an Array (Medium)

**Topic:** Heap | **Difficulty:** Medium

Return the kth largest array element, counting duplicates by position.

## TypeScript interface

`solve(nums: number[], k: number): number`

## Examples

- Input: `[[3,2,1,5,6,4],2]`; output: `5`.
- Input: `[[3,2,3,1,2,4,5,5,6],4]`; output: `4`.

Source: [LeetCode problem](https://leetcode.com/problems/kth-largest-element-in-an-array/)
