# Heap: Find K Closest Elements (Medium)

**Topic:** Heap | **Difficulty:** Medium

Return k sorted elements closest to x, preferring smaller values when distances tie.

## TypeScript interface

`solve(arr: number[], k: number, x: number): number[]`

## Examples

- Input: `[[1,2,3,4,5],4,3]`; output: `[1,2,3,4]`.
- Input: `[[1,2,3,4,5],4,-1]`; output: `[1,2,3,4]`.

Source: [LeetCode problem](https://leetcode.com/problems/find-k-closest-elements/)
