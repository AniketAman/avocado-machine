# Array: Move Zeroes (Easy)

**Topic:** Array | **Difficulty:** Easy

Move all zeroes to the end of the array in place while preserving the relative order of nonzero values.

## TypeScript interface

`solve(nums: number[]): void`

## Examples

- Input: `[0,1,0,3,12]`; output: `[1,3,12,0,0]`.
- Input: `[0,0,1]`; output: `[1,0,0]`.

Source: [LeetCode problem](https://leetcode.com/problems/move-zeroes/)
