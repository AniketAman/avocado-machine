# Math: Roman to Integer (Easy)

**Topic:** Math | **Difficulty:** Easy

Convert a valid Roman numeral to its integer value, including subtractive pairs.

## TypeScript interface

`solve(s: string): number`

## Examples

- Input: `"III"`; output: `3`.
- Input: `"MCMXCIV"`; output: `1994`.

Source: [LeetCode problem](https://leetcode.com/problems/roman-to-integer/)
