# Binary Tree: Path Sum II (Medium)

**Topic:** Binary Tree | **Difficulty:** Medium

Return all root-to-leaf paths whose node values sum to targetSum.

## TypeScript interface

`solve(root: TreeNode | null, targetSum: number): number[][]`

## Examples

- Input: `[[5,4,8,11,null,13,4,7,2,null,null,null,null,5,1],22]`; output: `[[5,4,11,2],[5,8,4,5]]`.
- Input: `[[1,2,3],5]`; output: `[]`.
