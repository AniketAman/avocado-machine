# Linked List: Palindrome Linked List (Easy)

**Topic:** Linked List | **Difficulty:** Easy

Determine whether the values in a singly linked list read the same forward and backward.

## TypeScript interface

`solve(head: ListNode | null): boolean`

## Examples

- Input: `[1,2,2,1]`; output: `true`.
- Input: `[1,2]`; output: `false`.
- Input: `[]`; output: `true`.

Source: [LeetCode problem](https://leetcode.com/problems/palindrome-linked-list/)
