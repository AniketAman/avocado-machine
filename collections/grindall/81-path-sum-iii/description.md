# Binary Tree: Path Sum III (Medium)

**Topic:** Binary Tree | **Difficulty:** Medium

Count downward paths with sum targetSum; a path may begin at any node.

## TypeScript interface

`solve(root: TreeNode | null, targetSum: number): number`

## Examples

- Input: `[[10,5,-3,3,2,null,11,3,-2,null,1],8]`; output: `3`.
- Input: `[[1,-2,-3],-1]`; output: `1`.
