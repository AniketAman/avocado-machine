# Stack: Asteroid Collision (Medium)

**Topic:** Stack | **Difficulty:** Medium

Simulate collisions between right-moving positive and left-moving negative asteroids; equal sizes destroy both.

## TypeScript interface

`solve(asteroids: number[]): number[]`

## Examples

- Input: `[5,10,-5]`; output: `[5,10]`.
- Input: `[8,-8]`; output: `[]`.
- Input: `[10,2,-5]`; output: `[10]`.

Source: [LeetCode problem](https://leetcode.com/problems/asteroid-collision/)
