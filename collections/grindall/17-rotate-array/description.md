# Array: Rotate Array (Medium)

**Topic:** Array | **Difficulty:** Medium

Rotate the array to the right by k positions in place.

## TypeScript interface

`solve(nums: number[], k: number): void`

## Examples

- Input: `[[1,2,3,4,5,6,7],3]`; output: `[5,6,7,1,2,3,4]`.
- Input: `[[-1,-100,3,99],2]`; output: `[3,99,-1,-100]`.

Source: [LeetCode problem](https://leetcode.com/problems/rotate-array/)
