# Linked List: Rotate List (Medium)

**Topic:** Linked List | **Difficulty:** Medium

Rotate a singly linked list right by k positions.

## TypeScript interface

`solve(head: ListNode | null, k: number): ListNode | null`

## Examples

- Input: `[[1,2,3,4,5],2]`; output: `[4,5,1,2,3]`.
- Input: `[[0,1,2],4]`; output: `[2,0,1]`.

Source: [LeetCode problem](https://leetcode.com/problems/rotate-list/)
