# Array: Gas Station (Medium)

**Topic:** Array | **Difficulty:** Medium

Find the unique starting station from which a full circular trip is possible, or return -1.

## TypeScript interface

`solve(gas: number[], cost: number[]): number`

## Examples

- Input: `[[1,2,3,4,5],[3,4,5,1,2]]`; output: `3`.
- Input: `[[2,3,4],[3,4,3]]`; output: `-1`.

Source: [LeetCode problem](https://leetcode.com/problems/gas-station/)
